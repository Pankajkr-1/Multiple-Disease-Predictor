🩺 Multiple Disease Predictor System

A Machine Learning based web application that predicts the likelihood of multiple diseases including:

- ❤️ Heart Disease
- 🩸 Diabetes
- 🧠 Parkinson’s Disease

This system helps users get early predictions based on input medical parameters, making it useful for awareness and preliminary analysis.

---

🚀 Features

- 🔍 Predicts multiple diseases in a single platform
- 📊 Uses trained Machine Learning models
- 💻 User-friendly interface (Streamlit-based)
- ⚡ Fast and accurate predictions
- 🧾 Separate modules for each disease

---

🧠 Technologies Used

- Python 🐍
- Scikit-learn
- Pandas & NumPy
- Streamlit (for web app)
- Machine Learning Algorithms

⚙️ How It Works

1. User selects the disease prediction type
2. Inputs required medical parameters
3. Model processes the input data
4. System displays prediction result

---



📸 Output

- Displays whether the person is likely to have the disease or not
- Simple and interactive UI
